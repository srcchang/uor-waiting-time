# Screenshots

The hero currently uses a CSS phone mockup (`src/components/PhoneMockup.astro`)
so the site does not depend on unshipped app screenshots.

When real screenshots are available, drop them here as WebP/PNG (390×844 or
1170×2532) and replace the mock rows with an `<Image />` inside the same phone
frame. Keep the frame, notch, and shadow so the hero layout does not change.

Suggested shots:

- `waits-light.webp` — park list with live wait times
- `ride-stats-light.webp` — ride detail / statistics
- `waits-dark.webp` — dark mode equivalent

Do not use App Store marketing screenshots with device frames baked in; the
site supplies the frame and shadow.
